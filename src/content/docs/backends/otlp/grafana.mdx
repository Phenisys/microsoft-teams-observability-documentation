Use this guide to send collector logs to **Grafana Cloud** through OTLP.

## 1. Get Grafana Cloud OTLP Credentials

From your Grafana Cloud stack, collect:

- OTLP gateway endpoint (region-specific)
- Basic auth credentials or token for OTLP logs ingestion

Typical endpoint format:

- `https://otlp-gateway.grafana.net/otlp/v1/logs`
- `https://otlp-gateway-prod-eu-west-2.grafana.net/otlp/v1/logs`

## 2. Configure Collector Output

```yaml
output:
  otel:
    - name: "grafana"
      enabled: true
      endpoint: "https://otlp-gateway.grafana.net/otlp/v1/logs"
      service_name: "msteams-callrecords"
      deployment_environment: "prod"
      headers:
        Authorization: "Basic <base64-credentials>"
```

## 3. Validate and Send One Cycle

```bash
ms-teams-agent validate --config ./config.yaml
ms-teams-agent test-connection --config ./config.yaml
ms-teams-agent run --config ./config.yaml --ignore-state
```

## 4. Verify Ingestion

Use a simple HTTP probe when needed:

```bash
curl -i "https://otlp-gateway.grafana.net/otlp/v1/logs" \
  -H "Authorization: Basic <base64-credentials>"
```

Then verify in Grafana Explore that records from `service_name=msteams-callrecords` are visible.

<Aside type="tip">
Create a starter dashboard panel filtered on `MSTeams_CallRecords_CallMetadata` and `MSTeams_CollectionHealth` to confirm both business and operational events arrive.
</Aside>
