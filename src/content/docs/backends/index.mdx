The collector exports Teams telemetry to one or more **backends**: **Dynatrace, Splunk, or any OTLP-compatible backend**. Each backend integration covers both the receiving side (platform configuration) and the collector output configuration.

## Supported Backends

| Backend | Type | Application included |
|---|---|---|---|
| **Dynatrace** | SaaS observability platform | Yes — Grail storage + dedicated dashboards app |
| **Splunk** | SIEM / analytics platform | Yes — Splunk app with HEC ingestion |
| **Grafana** | Observability platform | Yes — Grafana plugin app with native dashboards |
| **OTel / OTLP** | OpenTelemetry logs endpoint | No native app — forwards to any OTLP-compatible receiver |
| **Console** | Standard output | No — for local testing and debugging |

## Adding a New Backend

The collector supports multiple simultaneous outputs. You can enable more than one backend in your configuration by adding multiple entries under the `output` section. See the [Standalone Configuration](../collector/v2/configuration/) for details.
