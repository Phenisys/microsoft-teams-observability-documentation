Before configuring the Dynatrace integration, ensure the following are in place.

## Dynatrace Platform

This connector requires **Dynatrace SaaS with Grail enabled**.

<Aside type="caution">
Not supported: Dynatrace Managed (on-premise) and classic log management without Grail.
</Aside>

## Required Dynatrace Permissions

Your Dynatrace account must be able to:

| Action | Where |
|---|---|
| Create and manage log buckets | Grail settings |
| Create and manage OpenPipeline pipelines | OpenPipeline settings |
| Create Credential Vault entries | Settings -> Credential Vault |
| Manage outbound host allowlist | Settings -> Preferences |
| Install apps from Hub / Marketplace | Dynatrace Hub |
| Create API tokens | Access token settings |

## Required API Token Scope

Create an API token with:

| Scope | Purpose |
|---|---|
| `logs.ingest` | Send log records to Dynatrace |

<Aside type="note">
Keep this token secure. It is required in collector output configuration and can be stored in Credential Vault.
</Aside>

## Dynatrace Hub Access

Access to **Dynatrace Hub** is required to install the MS Teams Observability app. If Hub access is restricted, install via ZIP upload: <a href={`${import.meta.env.BASE_URL}backends/dynatrace/app/installation/`}>App Installation</a>.
