The MS Teams Observability application is installed in your Grafana environment and provides operational visibility into your Microsoft Teams estate. It queries the same Loki logs exported by the collector.

**Version:** 1.2.0 | **Developed by:** Phenisys | **Platform:** Grafana Plugin

The application has seven pages accessible from the sidebar navigation:

## Time Range Selector

Available on Calls, Users, Sites, and Issues pages. Uses Grafana's built-in time range picker. The selected range is persisted in the URL and applied to all LogQL queries on the page.

## Health Indicators

| Status | Visual | Meaning |
|--------|--------|---------|
| Good | Green | Call met quality thresholds |
| Poor | Orange/Red | Call had quality degradation |
| Unclassified | Grey | No quality data available |

## Demo Mode

The application supports a **Demo Mode** that generates mock data for evaluation without a real collector. Demo Mode can be enabled from the Configuration page.

<Aside type="note">
Live Mode requires a valid Phenisys license. See [License](../../../getting-started/license/) for how to obtain it.
</Aside>

## Common UI Patterns

### Navigation

All pages are accessible from the Grafana sidebar under **Apps → Microsoft Teams Observability**. Sub-pages (Calls, Sites, Users, Issues, Configuration) appear in the app's own navigation.

### Call Overview Drill-Down

Clicking a call ID on the Calls or Users page navigates to the Call Overview page with the full call analysis, including:

- **Verdict**: Overall call quality assessment
- **Evidence**: Network transport distribution, relay usage, public egress patterns
- **Participants**: Per-user health matrix with connection type, protocol, and endpoint signals
- **Streams**: Per-stream metrics (RTT, jitter, packet loss, frame rate)
- **Network**: IPs, ASNs, relay regions, shared IP detection

### GeoIP Map (Call Overview)

When the Subnet Location datasource is enabled, the Call Overview displays a geographic map of participants. The GeoIP feature can be explicitly toggled in Configuration for privacy compliance.
