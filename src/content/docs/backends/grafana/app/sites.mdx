The Sites page aggregates call quality by geographic location using your sites file. The default time range is 2 hours.

## KPI Summary

The header displays 6 key metrics with color thresholds:

| KPI | Description |
| --- | --- |
| **Total Sites** | Number of sites in your configuration |
| **NPA Compliance** | Percentage of sites meeting quality thresholds |
| **Call Quality** | Overall good call percentage across all sites |
| **Avg Latency** | Average RTT (ms) across sites |
| **Packet Loss** | Average packet loss (%) across sites |
| **Sites at Risk** | Number of sites with poor quality trends (color-coded: good/warning/bad) |

## Geographic Overview

- **Sites Map**: A geomap panel showing site locations.
- **NPA Compliance Donut**: Breakdown of sites as Compliant, Uncompliant, or Undetermined based on quality thresholds.

## Sites Requiring Attention

A table listing sites that need investigation: NPA-uncompliant sites or sites with more than 5% poor streams.

## Analytics

Four charts provide deeper analysis:

| Chart | Description |
| --- | --- |
| **Call Count by Site** | Horizontal bar chart (top 8 sites) |
| **Call Quality Distribution** | Donut chart of Good / Poor / Unclassified |
| **Call Quality by Site** | Stacked bar chart (top 10 sites) |
| **Root Causes** | Pie chart of quality degradation causes |

## Site Inventory

A full table of all sites with: location, call count, quality metrics (RTT, packet loss), and NPA compliance status.

## Filters

A chip-based filter bar with an **"Include unmapped subnets"** toggle to show calls from IPs not yet assigned to any site.

<Aside type="tip">
Sites are defined in your sites CSV file (see [Sites File Reference](../../../reference/sites-file/)). Ensure the file is up to date for accurate site-level analytics.
</Aside>
