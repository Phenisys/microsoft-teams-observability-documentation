The Sites tab aggregates call quality by geographic location using your subnets CSV mapping.

**Default time range:** Last 2 hours.

## Filter Bar

A chip-based filter bar allows narrowing results by site properties. An **"Include unmapped subnets"** toggle includes calls from IPs not yet assigned to any site.

## Dashboard

### Header KPIs

Six summary cards with color thresholds:

| KPI | Description |
| --- | --- |
| **Total Sites** | Number of sites in your configuration |
| **NPA Compliance** | Percentage of sites meeting quality thresholds |
| **Call Quality** | Overall good call percentage |
| **Avg Latency** | Average RTT across sites (ms) |
| **Packet Loss** | Average packet loss across sites (%) |
| **Sites at Risk** | Count of sites with poor quality trends (color-coded good/warning/bad) |

### Geographic Overview

- **Sites Map**: geomap panel with site locations
- **NPA Compliance Donut**: Compliant / Uncompliant / Undetermined breakdown

### Sites Requiring Attention

Table of sites needing investigation: NPA-uncompliant or more than 5% poor streams.

### Analytics

Four charts:

| Chart | Description |
| --- | --- |
| Call Count by Site | Horizontal bar (top 8) |
| Call Quality Distribution | Donut chart |
| Call Quality by Site | Stacked bar (top 10) |
| Root Causes | Pie chart |

### Site Inventory

Full table: location, call count, quality metrics, NPA status.

<Aside type="tip">
Sites are defined in your subnet location CSV uploaded in [Provisioning](../provisioning/). Keep it up to date for accurate analytics.
</Aside>
