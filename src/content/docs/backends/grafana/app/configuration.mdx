> **Tab label:** Status

The Configuration page (labeled **Status** in the UI) is the central hub for license status, feature monitoring, and connectivity testing.

## License Panel

Displays the current license status:

| Detail | Description |
| --- | --- |
| **License Status** | Active, Expired, or Missing |
| **Tenant ID** | Masked by default for security |
| **Expiration** | License expiry date |
| **Features** | List of enabled collectors |

## Feature Status Panel

An interactive table showing each collector feature and its current operational status:

| Column | Description |
| --- | --- |
| **Feature** | Collector name (Calls, PSTN, Direct Routing, Auto Attendant, Call Queue, Issues) |
| **Status** | Active, Disabled, or Error |
| **Details** | Error message or last collection timestamp |

## Outgoing Connections Panel

Tests connectivity to 4 external endpoints. Each can be tested individually with a ping:

| Endpoint | Purpose | URL |
| --- | --- | --- |
| **Microsoft Login** | OAuth2 token acquisition | `login.microsoftonline.com` |
| **Microsoft Graph** | Call records API | `graph.microsoft.com` |
| **GeoMap API** | IP geolocation | `ip-api.com` |
| **GitHub API** | Release checks | `api.github.com` |

Each test shows: connection status (success/failure), HTTP response code, and latency.

## Grafana App Configuration

A native Grafana provisioning page (`AppConfig`) is also available, including the **GeoIP toggle** to enable or disable the Subnet Location datasource for privacy compliance.

The Grafana app requires a valid Phenisys license for live mode. See [License](../../../getting-started/license/) for details on obtaining and managing your license.
