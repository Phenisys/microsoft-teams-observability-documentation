The Call Overview page provides a deep-dive analysis of a single MS Teams call. It is accessed by clicking a Call ID from the Calls or Users pages. The URL preserves the original time range (`from`/`to`) so navigation back is seamless.

The page is organized into a progressive disclosure layout with 7 sections:

## 1. Verdict (Header)

A quick summary bar showing:
- Call ID, start/end time, duration, organizer, call type, participant count
- Overall verdict with KPI row (Good / Poor / Unclassified)

## 2. Evidence

A filterable table classifying each stream by quality:

| Column | Description |
| --- | --- |
| **Stream** | Media type and participant |
| **Metric** | Quality metric tested (RTT, jitter, packet loss, etc.) |
| **Value** | Measured value |
| **Threshold** | Quality threshold for this metric |
| **Evidence** | Whether the metric passed or failed |
| **Severity** | Impact level of the failure |

Filter by participant to focus on specific users.

## 3. Participants

The Call Map panel (40% width) shows participant geographic locations when GeoIP is enabled, alongside a Call Details panel (60%) with metadata and timeline.

## 4. Streams

A comprehensive streams table with per-stream metrics:

| Column | Description |
| --- | --- |
| **Participant** | User display name |
| **Media** | Audio, Video, or Screen Sharing |
| **Direction** | callerToCallee or calleeToCaller |
| **IP** | Participant IP address |
| **Subnet** | Subnet classification |
| **Protocol** | UDP or TCP |
| **RTT** | Average round-trip time (ms) |
| **Jitter** | Average jitter (ms) |
| **Packet Loss** | Average packet loss rate (%) |
| **Codec** | Audio/video codec used |
| **Platform** | OS platform |
| **Device** | Endpoint device |

Also includes a **Call Timeline** chart showing stream overlaps over the call duration.

## 5. Network

Three panels for network diagnostics:

| Panel | Description |
| --- | --- |
| **IP Insights** | IP distribution by ASN, shared IP patterns, public egress detection |
| **Network Path** | Relay usage analysis, transport distribution (UDP vs TCP) |
| **IP Inventory** | Complete inventory of all IP addresses observed |

## 6. Endpoint

**Device Participants Matrix**: per-participant breakdown of platform, host device, audio input/output devices, signal/noise levels, CPU, and Teams client version.

**Bot Details Panel**: appears conditionally when bots participated in the call.

## 7. Advanced

Additional panels available via the scene framework:
- **AI Analysis Panel** — optional root cause analysis
- **Quality Timeseries Panel** — quality metrics over time
- **Root Cause Panel** — identified degradation causes

## GeoIP Map

When the Subnet Location datasource is enabled, the Call Overview's Call Map shows participant locations on a geographic map.

<Aside type="caution">
The GeoIP map sends participant IP addresses to ip-api.com for geolocation. Disable this feature in Configuration if your organization's privacy policy requires it.
</Aside>
