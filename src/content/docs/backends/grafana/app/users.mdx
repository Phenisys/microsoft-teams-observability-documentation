The Users page provides per-user analytics for every MS Teams user who made or received calls. The default time range is 7 days.

## Filter Bar

Chip-based filters (key/operator/value) synced to the URL, allowing complex queries like "platform = windows AND callHealth = poor".

## Users Table

Each row represents a user with grouped data:

### Identity
- Display name, email, AAD object ID

### Network
- IPs, subnets, protocols used, connection types, protocol statistics

### Calls
- Total, Good, Poor, Unclassified counts
- Average, minimum, and maximum call duration

### Devices
- Platforms used (Windows, macOS, iOS, Android, Web)
- Host devices, input/output audio devices
- Teams products and client versions

### Recent Calls
- Last 5 calls with Call ID, health, and duration
- Each Call ID links to the Call Overview with the time range preserved.

### Last Seen
- Timestamp of the user's most recent call

<Aside type="tip">
Click a Call ID in the Recent Calls column to drill into the Call Overview. The time range from the Users page is preserved in the navigation.
</Aside>
