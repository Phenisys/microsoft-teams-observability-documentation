The Issues tab displays Microsoft 365 service health incidents that may impact your Teams environment. Data comes from the `MSTeams_ServiceAnnouncement` log source.

**Default time range:** Last 7 days.

## Current Issues

Active incidents shown as expandable cards:

| Detail | Description |
| --- | --- |
| **ID** | Microsoft incident ID (e.g., EX1234567) |
| **Affected Service** | Feature or service impacted |
| **Severity** | Incident, Advisory, or Other |
| **Classification** | e.g., "Service degradation" |
| **Start Date** | When the incident was first reported |
| **Details** | Full description with scope, timeline of Microsoft updates (Markdown rendering) |

## Closed Issues

Resolved incidents in the selected time range, same format as current issues, with resolution date.

## Correlation

Use this tab to correlate call quality drops with known Microsoft incidents:

1. Notice a quality drop on Home or Sites
2. Check Issues for active incidents in the same timeframe
3. If a matching incident exists → Microsoft-side issue, no configuration change needed

<Aside type="note">
If dashboard quality drops while an active incident is shown, investigate the Microsoft-side impact before changing local configuration.
</Aside>
