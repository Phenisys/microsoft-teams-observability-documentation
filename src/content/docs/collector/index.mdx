The **MS Teams Observability Collector** (`ms-teams-agent`) retrieves Microsoft Teams telemetry and sends it to configured backends.

The collector is available in two active deployment variants: **v2 (current)** and a **Dynatrace Extension** that runs inside an ActiveGate. **v1 is deprecated**.

<Aside type="caution">
Use v2 for all new deployments. If you are still on v1, plan migration with <a href={`${import.meta.env.BASE_URL}collector/v2/migration/`}>Migrate from v1</a>.
</Aside>
