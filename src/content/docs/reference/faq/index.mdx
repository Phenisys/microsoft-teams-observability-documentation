## Quick View: License Setup by Mode

<Tabs>
  <TabItem label="Standalone">
Set `collection_config.license_file` in `config.yaml` to a local license path.  
Reference: <a href={`${import.meta.env.BASE_URL}getting-started/license/`}>License</a>, <a href={`${import.meta.env.BASE_URL}collector/v1/configuration/`}>Configuration</a>.
  </TabItem>
  <TabItem label="Dynatrace Extension">
Paste the full license JSON into the extension License field as a string, not a file path.  
Reference: <a href={`${import.meta.env.BASE_URL}getting-started/license/`}>License</a>, <a href={`${import.meta.env.BASE_URL}collector/extension/installation/`}>Extension Installation</a>.
  </TabItem>
  <TabItem label="Dynatrace App">
License status and health are shown in the app configuration panel; a missing or invalid license can block tenant initialization and configuration saves.  
Reference: <a href={`${import.meta.env.BASE_URL}backends/dynatrace/installation/`}>Dynatrace Installation</a>, <a href={`${import.meta.env.BASE_URL}backends/dynatrace/app/configuration/`}>Application Configuration</a>.
  </TabItem>
</Tabs>
