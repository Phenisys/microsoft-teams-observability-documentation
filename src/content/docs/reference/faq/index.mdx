## Missing Data Fast Path

1. Run collector checks in <a href={`${import.meta.env.BASE_URL}collector/troubleshooting/`}>Collector Troubleshooting</a>.
2. If collector checks are green, continue with backend troubleshooting:
   - <a href={`${import.meta.env.BASE_URL}backends/dynatrace/troubleshooting/`}>Dynatrace</a>
   - <a href={`${import.meta.env.BASE_URL}backends/splunk/troubleshooting/`}>Splunk</a>
   - <a href={`${import.meta.env.BASE_URL}backends/grafana/`}>Grafana</a>
